# Вывод в интернет и безопасность

Пока шлюз и дальний телефон в одной Wi-Fi — всё работает «как есть». Чтобы звонки и SMS доходили
**из любой точки**, шлюз должен быть доступен из интернета.

> ⚠ **Эта часть ещё не проверена вживую** — пока тестировалось только в одной Wi-Fi.

## Вариант 1 (рекомендуемый): VPN

Поднять **VPN** между локацией шлюза и дальним телефоном. Два удобных варианта:

- **Tailscale** (бесплатно, **без белого IP**): поставить Tailscale на оба телефона, софтфон
  регистрируется на Tailscale-адрес шлюза. Регистратор запоминает адрес по факту регистрации, так
  что роуминг телефона он переживает. Проще всего, когда белого IP нет.
- **WireGuard** (если белый IP есть): оба конца в одной VPN-подсети.

При VPN **пробросы портов не нужны**, STUN можно держать выключенным, а `5062`/RTP слушать только
на VPN-интерфейсе — снаружи порт не виден. Снимается и проблема безопасности, и возня с NAT.

## Вариант 2: белый IP + проброс портов

Телефон-шлюз за роутером с **белым (без CGNAT) IP**.

1. **DHCP-резервация** LAN-адреса шлюза по MAC Wi-Fi — чтобы не менялся.
2. **Проброс UDP** на роутере:

   | Внешний порт | → Внутренний (шлюз) | Что |
   |---|---|---|
   | UDP **5062** | `<LAN IP>:5062` | SIP (REGISTER, INVITE, MESSAGE…) |
   | UDP **RTP-диапазон** | `<LAN IP>:<тот же диапазон>` | звук, **1:1, те же номера портов** |

   > RTP пробрасывать **без трансляции номеров** — иначе звук уйдёт не туда.
3. Клиент нацелить на `<белый IP или домен>:5062`. Если есть DDNS — лучше по домену (переезд/смена
   IP тогда не ломает клиента).

## ⛔ Безопасность — обязательно прочитать

В режиме встроенного регистратора **аутентификации нет** (пароль пустой). Открытый в интернет
`5062` — это toll-fraud риск:

- чужой может **зарегистрироваться на твой номер** и перехватывать входящие звонки;
- заставить шлюз **звонить/слать по GSM наружу** — реальные деньги;
- SIP-сканеры постоянно щупают интернет.

Что делать (по убыванию надёжности):

1. **VPN (вариант 1)** — лучший вариант, снимает проблему целиком и не требует белого IP
   (Tailscale). Рекомендуется.
2. Если проброс — на роутере **ограничить источник**: разрешить UDP 5062/RTP только с IP твоего
   телефона/оператора, остальное — deny.
3. Следить за журналом: чужая регистрация с незнакомого IP — тревога.

> Правильная защита — SIP-аутентификация регистратора; сейчас её нет (осознанный TODO). До неё —
> VPN или allow-list по IP. Не выставляй `5062` в открытый интернет без одного из этих
> ограничений.
