# Как всё настроить с нуля (для новичка)

Простым языком, по шагам. Делай сверху вниз. Если что-то не так - смотри «Частые проблемы» в конце.

## Что это и что получится

Старый (дежурный) телефон с твоей домашней SIM лежит дома на зарядке. Он ловит входящие
**звонки и SMS** на домашний номер и через интернет отдаёт их на твой обычный телефон, где бы ты
ни был - **без роуминга и без чужих серверов**. Отвечать на звонки и писать SMS ты тоже можешь со
своего телефона, как будто ты дома.

**Что нужно иметь:**
- **Телефон-шлюз** - отдельный аппарат под домашнюю SIM (требования ниже). Стоит дома на зарядке
  и на Wi-Fi.
- **Твой телефон** - любой, с интернетом. На него поставим программу-звонилку (софтфон).
- **ПК с `adb`** - один раз, чтобы настроить шлюз по кабелю.

## Телефон-шлюз: какой подойдёт

- **Android 13 или новее**, процессор **arm64**, чип **Qualcomm (Snapdragon)** или **MediaTek**.
- **НЕ подойдёт:** Samsung на **Exynos**, аппараты с операторским замком (Verizon и т.п.).
- Чем дешевле - тем лучше, это «дежурная» трубка на зарядке.
- Проверить пригодность без установки (по USB с ПК):
  ```bash
  adb shell getprop ro.build.version.release    # должно быть >= 13
  adb shell getprop ro.product.cpu.abi          # должно быть arm64-v8a
  adb shell "dumpsys media.audio_policy | grep -E 'TELEPHONY_TX|TELEPHONY_RX'"
  ```
  Если в последней команде есть обе строки - аппарат кандидат.

## Часть 1. Готовим телефон-шлюз

> Это трек «без рута». Он держится на **Shizuku** - помощнике, который даёт приложению
> расширенные права без рута. Минус: **после перезагрузки телефона Shizuku гаснет**, и шлюз
> встаёт, пока не запустишь Shizuku заново. Поэтому телефон-шлюз **лучше не перезагружать** (или
> рутовать - тогда Shizuku поднимается сам, см. README).

1. **Включить отладку.** На шлюзе: Настройки → «О телефоне» → 7 раз нажать «Номер сборки» →
   появится «Для разработчиков». Зайти туда → включить **«Отладка по USB»**. Подключить к ПК
   кабелем, на телефоне нажать «Разрешить».
2. **Поставить Shizuku и приложение** (с ПК):
   ```bash
   adb install shizuku.apk
   adb install voice-sip-agent-selfhost.apk
   ```
3. **Запустить Shizuku:**
   ```bash
   P=$(adb shell pm path moe.shizuku.privileged.api | sed 's/package://;s/base.apk//' | tr -d '\r')
   adb shell "${P}lib/arm64/libshizuku.so"
   ```
   (Без ПК Shizuku можно запускать на самом телефоне через «Беспроводную отладку».)
4. **Открыть приложение** → нажать **«Grant Shizuku»** → «Разрешать всегда». В блоке
   **«Состояние»** все кружки должны стать **зелёными**, внизу - **«Gateway ready»**.
5. **Отключить экономию батареи** для приложения и для Shizuku (особенно ZTE/Nubia/Xiaomi),
   иначе система убьёт шлюз, пока тебя нет.
6. **Узнать IP телефона-шлюза** (запиши - пригодится):
   ```bash
   adb shell "ip -4 addr show wlan0 | grep -o 'inet [0-9.]*'"
   ```
   Порт шлюза - **5062** (менять не надо).
7. **Режим сервера уже включён** - больше в приложении трогать ничего не нужно. (Исключение -
   если потом не будет звука, см. «Частые проблемы» → звук.)

## Часть 2. Твой телефон (софтфон)

1. Поставь **baresip** (из F-Droid: `com.tutpro.baresip`). Именно его - Linphone, например,
   **не отправляет SMS**.
2. В baresip: **⋮ → «Профили»** → в поле адреса впиши (подставь IP шлюза из шага 6):
   ```
   sip:myphone@<IP-шлюза>:5062
   ```
   → нажми **«+»** → включи тумблер **«Регистрация»**. Пароль и прокси не нужны.
   > ⚠ **Порт `:5062` обязателен** прямо в адресе, иначе ничего не заработает.
3. Если аккаунт загорелся **зелёным** - софтфон зарегистрировался на шлюз. В пределах дома уже
   работает.

---

## Часть 3. Проверка дома (оба в одной Wi-Fi)

- Позвони на домашнюю SIM с любого другого телефона - в baresip должен прийти **входящий звонок**.
- Пошли SMS на домашний номер - придёт в baresip. Ответь из baresip - уйдёт по SIM шлюза.

Если звонки и SMS ходят - **ядро работает**. Осталось сделать так, чтобы работало и из поездки.

## Часть 4. Чтобы работало из любой точки (интернет)

Дома шлюз и телефон в одной Wi-Fi - всё просто. «Из поездки» нужен **прямой доступ** плюс **пароль
на шлюзе**.

### Прямой доступ (белый IP + проброс портов)
Подходит, если у твоего домашнего интернета **белый (публичный) IP** без CGNAT.
1. На роутере закрепи IP шлюза (DHCP-резервация по MAC), чтобы не менялся.
2. Пробрось на роутере **UDP SIP-порт** (по умолчанию `5062`; лучше сменить его на свой случайный
   из 20000-60000 в настройках приложения) → `<IP шлюза>:<тот же порт>`.
3. Пробрось **UDP-диапазон RTP** `30000-40000` → на те же порты шлюза (**1:1, без смены номеров**,
   иначе звук уйдёт не туда).
4. В софтфоне укажи `<твой белый IP>:<порт>` вместо локального.

### Обязательно: пароль на шлюзе
Для выхода в интернет на шлюзе **обязательно задай пароль SIP-регистратора**, а в софтфоне - впиши
тот же пароль. Это и закрывает toll-fraud риск.

![Задать пароль регистратора в настройках шлюза](images/security-01-set-password.png)

![Ввести тот же пароль в софтфоне baresip](images/security-02-softphone-password.png)

> ⛔ **Безопасность.** Открытый в интернет SIP-порт без пароля - риск: чужой может
> зарегистрироваться на твой номер или заставить шлюз звонить по GSM за твои деньги. Шлюз закрыт
> **паролем SIP-регистратора** (digest-аутентификация плюс авто-бан IP после 5 неудачных попыток за
> 60 с); пустой пароль выключает защиту, поэтому для интернета пароль обязателен. Нестандартный
> порт - лишь маскировка от сканеров, не защита. Подробно -
> [`internet-security.md`](internet-security.md).

## Частые проблемы

- **Аккаунт в baresip не зелёный (жёлтый/красный).** Проверь: порт `:5062` в адресе; транспорт
  **UDP**; на дальнем телефоне для домашнего теста **выключи сторонний VPN**; в приложении-шлюзе
  Shizuku зелёный; не прибила ли процесс экономия батареи.
- **Звонок соединяется, но друг друга не слышно.** Это **способ захвата звука** в приложении
  («Cellular audio»), не софтфон. Переключи его (на Nubia - **Direct telephony**). См.
  [`settings-ru.md`](settings-ru.md), раздел 4.4.
- **После перезагрузки шлюза всё отвалилось.** Погас Shizuku - запусти его заново (шаг 3). Без
  рута это нормально; рут решает штатно (README → «Shizuku после перезагрузки»).
- **SMS не уходят из софтфона.** Скорее всего это Linphone - он не шлёт SMS. Поставь **baresip**.
- **Две SIM (два шлюза).** Один софтфон держит два аккаунта - по одному на каждый шлюз. См.
  [`client-baresip.md`](client-baresip.md).
